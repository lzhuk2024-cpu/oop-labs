## Робота з репозиторієм у Visual Studio Code

1. Відкрити репозиторій на GitHub.
2. Клонувати репозиторій на комп’ютер:
  
   git clone https://github.com/lzhuk2024-cpu/oop-labs.git
   
3. Відкрити папку репозиторію у Visual Studio Code.
4. Редагувати файли та зберігати зміни за допомогою Ctrl + S.
5. Використовувати Git для збереження змін:
  
   git add .
   git commit -m "Оновлено навчальні матеріали"
   git push
   
## Структура репозиторію

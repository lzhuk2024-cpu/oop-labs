## Мета роботи
Навчитися створювати та запускати програми мовою Python у Visual Studio Code та Jupyter Notebook, а також оформлювати результати роботи.

## Хід роботи
1. Перевірив встановлену версію Python 3.12.3.
2. Встановив розширення Python, Jupyter та перевірив GitHub Copilot.
3. Створив файл my_first_app.py та запустив програму.
4. Створив Jupyter Notebook my_first_app.ipynb і виконав код Python.
5. Додав Markdown-комірку з описом програми.
6. За допомогою ШІ створив додаткову програму calculator.py та перевірив її роботу.

## Результати роботи
